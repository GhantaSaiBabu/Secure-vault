# 🔐 Secure Vault

[![Live Demo](https://img.shields.io/badge/Visit-Live%20App-brightgreen)](https://securevault-9ecg.onrender.com/login)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Secure Vault is a modern web-based password and secrets manager built with security-first principles. It allows users to securely store, manage, and access sensitive data like passwords, private notes, API keys, and credentials — all from a simple and elegant interface.

---

## 🚀 Live Website

🔗 [https://securevault-9ecg.onrender.com/login](https://securevault-9ecg.onrender.com/login)

---

## 🔑 Key Features

- 🔐 End-to-End Encrypted Vault Storage  
- 👥 User Authentication (Login/Register)
- 🔒 Secure Password Hashing (e.g., bcrypt)  
- 🔑 Credential Manager: Save username/passwords securely  
- 📝 Notes/Secrets Storage  
- 📬 Contact/Support Form  
- 💻 Clean, responsive UI with dashboard
